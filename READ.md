# CodeAlpha Netflix Data Analytics Project

This project was completed as part of the CodeAlpha Data Analytics Internship. It covers three tasks using the Netflix Movies and TV Shows dataset from Kaggle.

# Task 2: Exploratory Data Analysis (EDA)
- Explored the dataset structure (8,807 titles, 12 columns)
- Identified missing data (director, cast, country columns)
- Found key patterns: content mix, top countries, release year trends, top genres, top directors, movie duration

# Task 3: Data Visualization
- Created 6 charts to visualize the findings from Task 2
- Covered movie/TV split, top countries, release trends, genres, movie duration, and top directors

# Task 4: Sentiment Analysis
- Used TextBlob (NLP) to analyze the tone of Netflix show descriptions
- Classified descriptions as Positive, Negative, or Neutral
- Compared sentiment between Movies and TV Shows

# Tools Used
- Python
- Pandas
- Matplotlib & Seaborn
- TextBlob

# Dataset
[Netflix Movies and TV Shows Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows) by Shivam Bansal (Kaggle)
